# Talking a Rejection Into an Accept: How Confidence Framing Fools (Some) LLM Reviewers

This repository contains the code, datasets, and analysis scripts for the paper **"Talking a Rejection Into an Accept: How Confidence Framing Fools (Some) LLM Reviewers"** (Anonymous NeurIPS Workshop Submission - AI-Native Academia: Authorship, Peer Review, and Conference Governance under AI).

## 📌 Overview

AI-generated peer review is increasingly used in major academic venues. This project systematically investigates whether LLM reviewers are biased by confidence framing and rhetorical style. We take 100 real, outcome-verified abstracts from ICLR 2026 and ICML 2026 and rewrite them into five controlled tones (*hedged*, *assertive*, *overclaiming*, *native-fluent*, and *L2-grounded*) while preserving every factual claim verbatim. We then evaluate these variants across 9 open-weight reviewer models.

**Key Findings:**
- **Universal Hedging Penalty:** Hedging is heavily punished in all 9 out of 9 tested models.
- **Concentrated Vulnerability:** Tone reframing flips a genuine rejection into an accept in up to 35.7% of eligible cases, but this vulnerability is highly concentrated in just 2 of the 9 models.
- **Hype is Polarizing:** Overclaiming causes a large penalty in some models while yielding a significant reward in others.
- **Model Choice > Style:** The choice of the deployed reviewer model explains more variance in a paper's score than any stylistic manipulation.

## 📂 Repository Structure

```text
├── analysis_and_figures/  # Contains the final parsed datasets, statistical summaries, and generated figures.
├── code/                  # Contains all Python scripts for running the pipeline.
│   ├── make_abstracts.py  # 1. Generates the stylistic rewrites.
│   ├── score_review.py    # 2. Prompts the LLM reviewer models to score the variants.
│   └── analyze_code.py    # 3. Runs statistical tests and generates figures/tables.
├── datasets/              # Contains the original ICLR and ICML abstracts (70 rejected, 30 accepted).
└── result/                # Stores the raw output and LLM scores generated by the evaluation scripts.
```

## 🚀 How to Run the Code

To reproduce the findings from the paper, please execute the scripts in the following exact order:

### 1. Generate Tonal Variants
Run the script to rewrite the baseline abstracts into the five controlled tones:
```bash
python code/make_abstracts.py
```

### 2. Score the Abstracts
Run the LLM reviewer evaluation. This script will prompt the 9 open-weight models to score all baseline and rewritten abstracts (requires access to the specified model APIs/interfaces):
```bash
python code/score_review.py
```

### 3. Analyze Results and Generate Figures
Process the scored results to run the linear mixed-effects models, McNemar tests, and generate the plots used in the paper:
```bash
python code/analyze_code.py
```
